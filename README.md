# Kiwi Araga Bot

Telegram-бот с персоной **Киви Арага** (Леопард из «Магической Девочки-Разрушительницы»):
капризная, эмоциональная, влюблённая. Общается через LLM (Groq via litellm), понимает текст,
голосовые сообщения и фото (vision), помнит историю диалога и профиль пользователя.

## Требования

- Python 3.14
- [uv](https://docs.astral.sh/uv/)
- Токен бота от [@BotFather](https://t.me/BotFather) и ключ [Groq](https://console.groq.com/)

## Настройка

```bash
cp .env.example .env   # вписать TELEGRAM_BOT_TOKEN и GROQ_API_KEY
uv sync
```

Переменные окружения (см. `.env.example`):

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от @BotFather | — |
| `GROQ_API_KEY` | ключ Groq | — |
| `GROQ_MODEL` | LLM для ответов | `groq/llama-3.3-70b-versatile` |
| `GROQ_STT_MODEL` | модель распознавания голоса | `groq/whisper-large-v3` |
| `GROQ_VISION_MODEL` | модель для фото (vision) | `groq/meta-llama/llama-4-scout-17b-16e-instruct` |
| `HISTORY_LEN` | сколько строк истории помнить | `20` |
| `MAX_INPUT` | потолок длины входящего сообщения (символов) | `2000` |
| `SUMMARY_EVERY` | обновлять досье о собеседнике каждые N его ходов | `20` |
| `DB_FILE` | файл SQLite-состояния | `state.db` |
| `LOG_FILE` | файл лога | `bot.log` |
| `RATE_LIMIT` / `RATE_WINDOW` | лимит сообщений за окно (сек) | `5` / `30` |
| `LLM_TIMEOUT` | таймаут вызовов LLM/STT (сек) | `60` |
| `MAX_VOICE_SEC` | потолок длительности голосового (сек) | `120` |

Список доступных моделей Groq: `uv run python scripts/list_models.py`.

## Запуск

```bash
uv run python -m kiwi        # polling
docker compose up -d --build # или в Docker (состояние в ./data)
```

## Команды бота

- `/start` — привет и что умеет
- `/menu` — выбрать, в кого Киви влюблена (в Утену / в тебя) — только в личке
- `/me` — что бот о тебе знает — только в личке
- `/reset` — забыть историю разговора — только в личке
- `/enable` / `/disable` — включить/выключить Киви в группе (только админ группы)

## Группы

В группе Киви молчит, пока админ не позовёт её командой `/enable`. После этого она отвечает
только когда к ней обращаются: упоминание `@bot` или reply на её сообщение (privacy mode у
@BotFather можно оставить включённым). История в группе общая на комнату: реплики участников
подписываются именами (`[Имя] текст`), чтобы Киви различала собеседников. Персональный профиль
(`/me`, режим влюблённости) и досье-память в группе не ведутся.
